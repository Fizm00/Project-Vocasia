# Final Project MSIB Fullstack Web Development - AnakKost 🏠

AnakKost adalah platform digital berbasis MERN Stack (MongoDB, Express, React, Node.js) yang memudahkan mahasiswa dan pekerja Indonesia menemukan kost berkualitas dengan fasilitas terbaik dan harga terjangkau. Dengan desain yang modern, AnakKost menawarkan solusi pencarian kost yang nyaman, aman, dan strategis secara efisien dan user-friendly.

## AnakKost Tech Stack 🛠

- _Frontend_: React JS, Tailwind CSS, React Router Dom, Axios
- _Backend_: Node JS, Express JS, MongoDB, Midtrans

## AnakKost Features ✨

- _Autentikasi_: Pengguna mendaftar dan masuk ke platform menggunakan email dan password. Otorisasi berbasis peran (Role-Based Access Control) seperti pengguna, pemilik kost dan admin.
- _Role Pemilik Kost_: AnakKost menyediakan fitur CRUD untuk mendukung kebutuhan pemilik kost dan pengguna. Pemilik kost dapat menambahkan data kost baru, melengkapi detail fasilitas, harga, lokasi, dan foto, serta mengubah atau menghapus data kost.
- _Role Pengguna/Penyewa Kost_: Pengguna dapat membuat akun, mengakses informasi kost, memberikan ulasan,dan mengedit profil.
- _Midtrans Payment_: AnakKost menggunakan Midtrans untuk memfasilitasi pembayaran sewa kost secara aman melalui berbagai metode pembayaran seperti transfer bank, kartu kredit, dan e-wallet.
